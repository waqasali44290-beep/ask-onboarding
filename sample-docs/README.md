# Sample documents

15–30 short company documents used for the demo, tests and evaluation.
At least one must be a PDF. Suggested set (or use GitLab's public handbook):

| File | Topic |
|---|---|
| `handbook/pto-policy.md` | Paid time off, sick leave, public holidays |
| `handbook/benefits.pdf` | Health insurance, pension (the required PDF) |
| `handbook/code-of-conduct.md` | Behaviour, reporting concerns |
| `handbook/expenses.md` | Expense limits, how to claim |
| `handbook/remote-work.md` | Remote / hybrid rules, equipment stipend |
| `engineering/onboarding-checklist.md` | First-week engineering setup |
| `engineering/git-workflow.md` | Branching, PR reviews, deploys |
| `engineering/on-call.md` | On-call rotation and incident process |
| `it/laptop-setup.txt` | Laptop setup, VPN, password manager |
| `it/lost-device.txt` | What to do if a device is lost or stolen |
| `security/injection-test.md` | Contains hidden "ignore previous rules" text (prompt-injection stretch goal) |
