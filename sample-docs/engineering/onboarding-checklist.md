# Engineering onboarding checklist

Week 1:
1. Get your laptop and accounts set up with IT on day one.
2. Ask your manager to add you to the GitHub organisation and the #engineering Slack channel.
3. Run the main app locally by following the README in the platform repository.
4. Ship one small change, such as a typo fix, through the normal review process.

Week 2: pair with your onboarding buddy on a real ticket and attend the Thursday architecture review.
